# دليل الكود (للمذاكرة)

## الصورة الكبيرة
```
المتصفح  (static/index.html: واجهة + منطق)
   │  طلبات JSON على /api/...  (كوكي الجلسة HttpOnly)
   ▼
server.py  (سيرفر Python + التحقق + الصلاحيات)
   │  SQL
   ▼
data/loader.db  (SQLite، بتتنشئ أول تشغيل)

desktop.py = يشغّل السيرفر ويفتح Edge/Chrome في نافذة تطبيق بدون شريط عنوان.
```
- **مكتبة بايثون القياسية فقط** (مفيش تسطيب مكتبات).
- الحسابات (الأسعار، الضريبة، الكميات) بتتحسب في **السيرفر** مش في الشاشة.

## خريطة الملفات
| الملف | فيه إيه |
|---|---|
| `server.py` | الجداول (`init`)، تشفير كلمات المرور (`hp`/`chk`)، الجلسات (`H.me`)، كل الـ API (`H.route`)، الفاتورة (`H.invoice`) |
| `static/index.html` | الصفحات والتنقل والنماذج + الأوامر الصوتية + البحث بالصورة + المساعد |
| `desktop.py` | مشغّل الديسكتوب |
| `install.ps1` / `build-exe.bat` / `installer.iss` | اختصار الأيقونة / بناء exe / ملف تسطيب (لم تُختبر على ويندوز) |
| `assets/`, `static/logo.png` | اللوجو والأيقونة |

## الـ API (في `H.route`)
| الطلب | المسموح | بيعمل إيه |
|---|---|---|
| POST `/api/login` | الكل | تحقق من كلمة المرور + نوع الدخول (مدير/موظف) + إنشاء جلسة |
| POST `/api/register` | الكل | حساب جديد بحالة `pending` |
| GET `/api/me`, POST `/api/logout` | مسجّل دخول | بيانات المستخدم / إنهاء الجلسة |
| GET `/api/users`, POST `/api/users/<id>/approve` | مدير | قائمة المستخدمين وموافقة الحسابات |
| GET/POST `/api/products` ... `/<id>` PUT/DELETE | مدير (الموظف قراءة فقط) | المخزون |
| `/api/suppliers`, `/api/purchases`, `/api/payments`, `/api/expenses` | مدير | CRUD عام (نفس الكود لكل الجداول عبر القاموس `ENT`) |
| `/api/customers` | مدير + موظف | العملاء |
| GET/POST `/api/invoices` | مدير + موظف | الفواتير؛ الـ POST فيه المعاملة (`H.invoice`) |
| GET/PUT/DELETE `/api/product_images` | قراءة للكل، كتابة للمدير | الصور المرجعية للبحث بالصورة |

الصلاحيات في القاموس `EMP` أعلى `server.py`: أي مسار غير موجود فيه الموظف بياخد 403.

## أهم 3 حاجات تتفهم كويس
1. **تسجيل الدخول**: `hp()` بيعمل PBKDF2 مع salt، `chk()` بيقارن، والجلسة token عشوائي محفوظ في جدول `sessions` ومبعوت في كوكي `HttpOnly`.
2. **الفاتورة** (`H.invoice`): `begin immediate` ← يقرأ سعر كل صنف **من القاعدة** (مش من الشاشة) ← يتأكد من الكمية ← يحسب الضريبة 14% ← يسجل الفاتورة وبنودها وينقص المخزون ← `commit`. أي خطأ في النص = لا شيء يتسجل.
3. **CRUD العام**: `ENT` بيحدد أعمدة كل جدول، والكود العام بيبني الـ INSERT/UPDATE منه، ويحوّل الأرقام تلقائيًا.

## الواجهة (`static/index.html`) — الدوال حسب الموضوع
- **الاتصال والجلسة:** `api()`, `loadAll()`, `startApp()`, `enter()`, `out()`, `setA()` + معالج نموذج الدخول.
- **التنقل والصفحات:** `draw()`, `nav()`, `home()`, `crud()` (صفحة عامة للمخزون/الموردين/العملاء/...)، `sale()`, `zk()` الزكاة, `rep()` التقارير, `set()` الإعدادات.
- **النماذج والفاتورة:** `openM()`, `del()`, `addI()`, `save()`.
- **الأوامر الصوتية:** `AR()` تطبيع الحروف العربية، `parseNums()` الأرقام بالكلام، `lev()`/`bestMatch()` التطابق التقريبي، `one()` فهم الأمر، `runVoice()`, `vsay()`, `listen()`.
- **البحث بالصورة:** `pix()` يصغّر الصورة، `featOf()` يستخرج الخصائص (ألوان + HOG + صورة مصغّرة)، `rank()` التشابه الجيبي، `imgSearch()`, `refPhoto()`.
- **المساعد:** `bot()` (القواعد + `FAQ` + قوائم `DOM`/`OFF` اللي بتحدد المجال)، `botSend()`.

## تتبّع عملية بيع من الأول للآخر
`sale()` يرسم الشاشة ← `addI()` يضيف البند للمتغير `inv` ← `save()` يبعت `POST /api/invoices` ← `H.invoice()` يتحقق ويحسب ويخصم ← الرد يرجع ← `loadAll()` يحدّث الكميات ← `draw()` يعيد الرسم.

## توزيع المذاكرة (كل واحد يشرح جزءه 5 دقايق للباقي)
| العضو | يذاكر ويشرح |
|---|---|
| مصطفى (Frontend 1) | `setA` + معالج الدخول + `home()` + الصلاحيات في `nav()` |
| محمد (القائد) | الصورة الكبيرة، `desktop.py`، دورة Git/Jira |
| أبو بكر (Frontend 2) | `sale()`, `addI()`, `save()` + الأوامر الصوتية |
| خالد (Frontend 3) | `crud()` والبحث والفلترة، صفحات العملاء والموردين |
| عبد الباسط (Frontend 4) | `openM()` والنماذج، التقارير والإعدادات، الوضع الليلي |
| صبحي فرجاوي (Backend A) | `hp`/`chk`، الجلسات، `H.me`، `EMP` والصلاحيات |
| عمار (Backend B) | `init()` وتصميم الجداول، `H.invoice()` والمعاملة |
| الحسين (Backend C) | CRUD العام (`ENT`)، `product_images`، التحقق من القيم |
| يوسف فايز (QA) | يجرّب الـ API بـ curl ويكتب حالات الاختبار، ويتأكد من 403 للموظف |
| العضو العاشر | `install.ps1`, `build-exe.bat`, `installer.iss`، والـ README |

## أسئلة متوقعة من الدكتور (جاوبوا بكلامكم)
1. ليه السعر والضريبة بيتحسبوا في السيرفر؟ — الشاشة ممكن تتلاعب فيها.
2. إيه اللي بيحصل لو اتبعت بيعتين في نفس اللحظة؟ — المعاملة (`begin immediate`) بتمنع بيع أكتر من المخزون.
3. إزاي بتتخزن كلمات المرور؟ — PBKDF2 + salt، مش نص عادي.
4. إزاي البحث بالصورة بيشتغل، وإيه حدوده؟ — خصائص يدوية + تشابه جيبي، مش شبكة عصبية، ودقته اتقاست على صور مولّدة بس.
5. المساعد بيرفض الأسئلة بره المجال إزاي؟ — قواعد ثابتة (`DOM`/`OFF`) مش نموذج لغوي مفتوح.
6. إيه اللي لسه ناقص؟ — شوفوا ملف «ما ينقص المشروع».
