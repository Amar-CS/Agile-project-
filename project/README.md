# Loader Store — نظام إدارة متجر قطع غيار اللودر

## التشغيل (بدون تثبيت أي مكتبات)
المطلوب: Python 3.8 أو أحدث فقط.
- ويندوز: دوس دبل كليك على `run.bat`  (أو في الطرفية: `python server.py`)
- ماك/لينكس: `./run.sh`
بعدها افتح المتصفح على: http://127.0.0.1:8000
أول تشغيل بينشئ قاعدة البيانات `data/loader.db` ويحط فيها بيانات تجريبية.
لتغيير المنفذ: `PORT=9000 python server.py`

## تشغيله كبرنامج ديسكتوب (نافذة مستقلة)
- ويندوز: دبل كليك على `run-desktop.bat`. بيفتح Edge أو Chrome في نافذة بدون شريط المتصفح، وبيقفل السيرفر لما تقفل النافذة.
- لعمل اختصار على سطح المكتب: كليك يمين على `run-desktop.bat` ثم Send to ثم Desktop (create shortcut).
- لو مفتحش حاجة، شغّل `run.bat` عشان تشوف رسالة الخطأ.

## تشغيله كبرنامج عادي بلوجو (3 مستويات)
1. **اختصار بالأيقونة (الأسهل):** دبل كليك على `install.bat` مرة واحدة، فيظهر «Loader Store» بالشعار على سطح المكتب وفي قائمة Start، ويتفتح بدون نافذة سودا. محتاج Python متسطّب.
2. **ملف تنفيذي `LoaderStore.exe`:** دبل كليك على `build-exe.bat` (محتاج إنترنت مرة لتنزيل PyInstaller). الناتج `dist\LoaderStore.exe` بأيقونة الشعار ومن غير نافذة سودا، وبياناته في `%APPDATA%\LoaderStore`.
3. **ملف تسطيب `LoaderStore-Setup.exe`:** بعد الخطوة 2، افتح `installer.iss` في برنامج Inno Setup (مجاني) واضغط Compile. الناتج بيسطّب البرنامج ويعمل اختصار وقائمة Start وزر إلغاء تسطيب.
الأيقونة في `assets/loader-store.ico` والشعار في `static/logo.png`.

## الحسابات التجريبية (غيّر كلمات المرور قبل أي استخدام حقيقي)
- مدير: admin@loader.com / 123456   (اختر تبويب "مدير")
- موظف: staff@loader.com / 123456   (اختر تبويب "موظف")
أي حساب جديد من "إنشاء حساب" بيبقى قيد الموافقة، والمدير بيوافق عليه من الإعدادات.

## هيكل المشروع
- `server.py`  السيرفر وقاعدة البيانات (SQLite) والـ API — مكتبة بايثون القياسية فقط
- `desktop.py`  مشغّل الديسكتوب (سيرفر + نافذة تطبيق)
- `static/index.html`  الواجهة (HTML/CSS/JavaScript)
- `data/loader.db`  قاعدة البيانات (بتتنشئ تلقائيًا؛ احذفها لإعادة البيانات التجريبية)

## اللي شغال فعليًا
- تسجيل دخول حقيقي: كلمات المرور مشفّرة (PBKDF2)، جلسة بكوكي HttpOnly، تسجيل خروج.
- صلاحيات تتفرض على السيرفر: الموظف يقرأ المخزون ويتعامل مع العملاء والفواتير فقط (باقي الطلبات ترجع 403).
- إضافة/تعديل/حذف: المخزون، الموردين، العملاء، المشتريات، المدفوعات، المصروفات.
- فاتورة المبيعات: السعر والضريبة 14% بتتحسب في السيرفر، والكمية بتتخصم من المخزون في عملية واحدة، ومينفعش تبيع أكتر من المتاح.
- طلبات التسجيل وموافقة المدير.

## الفيتشرز الإبداعية
**1) أوامر صوتية بالعامية المصرية** (صفحة فاتورة المبيعات): اضغط 🎤 وقول مثلًا «ضيف اتنين فلتر زيت»، «خصم خمسين»، «العميل أحمد محمد»، «شيل التيل»، «كام مبرد زيت»، «احفظ الفاتورة». يفهم الأرقام بالكلام (خمسة وعشرين، مية وخمسين) وبالأرقام العربية، ويصحّح أخطاء النطق/الإملاء البسيطة، ويفهم أكتر من أمر في جملة بـ «وكمان».
- الميكروفون يحتاج Chrome أو Edge + إنترنت (الصوت بيتحول لنص عن طريق خدمة المتصفح) + السماح بالميكروفون.
- بدون ميكروفون: اكتب الجملة نفسها في الخانة واضغط Enter، وتنفّذ بنفس الطريقة.
**2) بحث بالصورة** (صفحة المخزون): المدير يضغط 📷 جنب أي صنف ويرفع صورته المرجعية. بعدها زر «📷 بحث بالصورة» يحلّل صورة القطعة ويعرض أقرب 3 أصناف مع نسبة التشابه، وزر لإضافة الصنف للفاتورة.
- الطريقة: استخراج خصائص (توزيع الألوان + اتجاهات الحواف HOG + نسخة مصغّرة) ومقارنتها بالتشابه الجيبي (Cosine). مش شبكة عصبية، فأفضل نتيجة مع خلفية سادة وإضاءة جيدة وصورة مرجعية لكل صنف.

**3) مساعد المتجر (زر 💬 أسفل الشاشة)**: بيجاوب فقط على أسئلة الشغل: كمية وسعر أي صنف، الأصناف الناقصة، المبيعات والفواتير، أرصدة العملاء، بيانات الموردين، وطريقة استخدام النظام. أي سؤال خارج المجال (شعر، سياسة، برمجة، نكت...) بيرفضه برسالة ثابتة، وأي طلب تعديل بيرد بأنه للاستعلام فقط. مبني بقواعد ثابتة (مش نموذج مفتوح)، فمفيش طريقة لإقناعه يتكلم في حاجة تانية. والموظف مش بياخد معلومات المدير (الأرباح، المصروفات، الموردين، التكلفة).

## حدود معروفة (مش مكتملة)
- المساعد بيفهم صيغ الأسئلة المكتوبة فيه فقط؛ سؤال بصيغة غريبة عن المتجر ممكن يرد بـ «ما قدرتش أفهم» ويقترح أمثلة.
- البحث بالصورة اتجرّب على صور مولّدة فقط؛ لازم تقيس دقته على صور حقيقية لقطعكم قبل ما تعتمدوا على أرقامه. وعتبات «تطابق قوي/محتمل» مضبوطة على الصور المولّدة.
- فواتير المشتريات بتتسجل كسجل فقط ولا تزوّد المخزون، والمدفوعات لا تعدّل أرصدة العملاء.
- الرسم البياني ونسب التغيّر في الرئيسية وعدّاد "فواتير اليوم" قيم تجريبية ثابتة، و"الأرباح" تقدير ثابت (26% من المبيعات).
- "نسيت كلمة المرور" لا يرسل بريدًا فعليًا.
- جلسات الدخول لا تنتهي تلقائيًا، ولا يوجد HTTPS أو حد لمحاولات الدخول (مناسب للمشروع الدراسي والتشغيل المحلي فقط).
